## Lista para os detalhes

Na lista, as tarefas são agrupadas por status. O título fica em destaque, acompanhado de prioridade, contador de subtarefas e status. Expanda uma linha para trabalhar no checklist sem perder o contexto.

![Lista de tarefas agrupada por status, com uma tarefa pendente](/docs/screens/lista.png)

## Quadro para acompanhar o fluxo

Selecione **Quadro** para visualizar as colunas **Pendente**, **Em andamento** e **Concluído**. Arraste cartões entre colunas para mudar o status. O botão de adicionar na coluna abre a criação de tarefa.

![Quadro Kanban do espaço com as três colunas de status](/docs/screens/kanban.png)

## Busca, filtros e ordenação

| Controle | Comportamento |
| --- | --- |
| Todas / Pendente / Em andamento / Concluído | Restringe por status |
| Filtrar tarefas no espaço | Busca no título e na descrição |
| Todas as prioridades | Restringe por prioridade |
| Ordem manual | Usa a posição das tarefas |
| Prazo | Ordena pela data; tarefas sem prazo ficam depois |
| Prioridade | Urgente, Alta, Média e Baixa |
| Título | Ordem alfabética |

**Para reorganizar manualmente**, volte a **Todas**, limpe a busca e o filtro de prioridade e selecione **Ordem manual**. A interface restringe o arraste quando há filtros ou outra ordenação para evitar posições ambíguas.

## Sua visualização padrão

Em **Configurações → Aparência**, escolha **Lista / Checklist** ou **Quadro / Kanban**. A preferência é guardada neste navegador. Você ainda pode alternar a visualização pelo controle do espaço.
