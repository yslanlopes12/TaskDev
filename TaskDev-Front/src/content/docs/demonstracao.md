## Um espaço para aprender fazendo

O exemplo abaixo reproduz os controles de lista, status, prioridade e checklist usando componentes visuais do projeto. Alterne entre lista e quadro, marque subtarefas e mude o status da tarefa.

**É uma simulação local.** Nenhuma conta é necessária, nenhuma requisição é enviada para a API ou para um provedor de IA e nenhum dado é salvo. Recarregar a página ou usar **Recomeçar** restaura o exemplo. O XP considera uma tarefa de prioridade média e seis subtarefas: cada item vale 5 XP e a conclusão do pai concede o restante até 30 XP, marcando todo o checklist. Reabrir remove apenas a recompensa do pai.

## Leve o fluxo para sua rotina

Experimente o exemplo e depois [crie sua primeira tarefa](/docs/primeiros-passos). Na aplicação real, os dados e as recompensas são validados pela API e persistidos no PostgreSQL.
